# virtualassist-connect

AI-powered virtual assistant application with structured AI-driven development lifecycle.

## Project Structure

- **backend/**: Python Lambda functions (to be implemented)
- **frontend/**: Angular application (to be implemented)
- **infra/**: AWS CDK infrastructure definitions (to be implemented)
- **docs/**: Project specifications and SDLC workflows
- **skills/**: AI skill definitions for development automation
- **tests/**: Integration and E2E tests (to be implemented)

## Technology Stack

- Backend: AWS Lambda (Python)
- Frontend: Angular
- Infrastructure: AWS CDK (Python)
- AI: Generative AI libraries (Anthropic Claude, LangChain)

## SDLC Process

Follow the workflows in `docs/workflows/`:
1. Requirements Gathering
2. Design & Architecture
3. Task Elaboration
4. Implementation
5. Testing
6. Deployment

## Getting Started

See workflow documentation in `docs/workflows/` to begin the development process.
